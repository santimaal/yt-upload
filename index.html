yt-upload

A private, internal command-line tool that uploads videos to two YouTube channels owned by the same creator.

▶ YouTube This tool uses the YouTube API Services.

What it does

yt-upload runs only on the channel owner's own computer. It reads a local file with a video's title, description, tags, scheduled publish time, playlist, thumbnail and pinned-comment text, and uploads it with the YouTube Data API to one of these two channels:

  • Últimos Minutos (Spanish)
  • Final Minutes (English)

It is not distributed, sold or offered to anyone else, it has no other users, and it does not read or display other people's YouTube data.
