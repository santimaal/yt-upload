Privacy Policy

Last updated: 23 November 2026

yt-upload ("the tool") is a private command-line tool used only by its author, the owner of the YouTube channels Últimos Minutos and Final Minutes, to upload videos to those two channels. This policy explains what data the tool handles.

YouTube API Services

The tool uses the YouTube API Services. By using the tool you agree to be bound by the YouTube Terms of Service. YouTube data is also governed by the Google Privacy Policy.

Data the tool accesses

When the channel owner authorizes the tool with Google OAuth, it requests two permissions on the owner's own channel:

  • youtube.upload, to upload videos;
  • youtube.force-ssl, to set thumbnails, add videos to playlists, post the owner's own comment on the owner's own videos, and read the name of the authorized channel (to check that the right channel was chosen).

The tool does not access, read or collect data about any other YouTube user or channel, and it does not show YouTube content to anyone.

Data the tool stores

  • OAuth tokens for the owner's two channels, stored only in a local folder on the owner's computer.
  • An upload log (video ID, title and upload date of each video the owner has uploaded with the tool), stored only on the owner's computer to avoid uploading the same video twice.

No data is stored on any server, and nothing is sold, shared with or disclosed to third parties. The tool uses no cookies, analytics or advertising.

Retention and deletion

Stored data is kept only while the owner uses the tool. It can be deleted at any time by deleting the local tokens folder and upload log.

Access can be revoked at any time from the Google security settings page: https://security.google.com/settings/security/permissions. When access is revoked, the stored tokens stop working and can then be deleted.

Política de privacidad

Última actualización: 23 de noviembre de 2026

yt-upload («la herramienta») es una herramienta privada de línea de comandos que solo usa su autor, el propietario de los canales de YouTube Últimos Minutos y Final Minutes, para subir vídeos a esos dos canales.

Servicios de API de YouTube

La herramienta usa los Servicios de API de YouTube. Al usarla aceptas los Términos del Servicio de YouTube. Los datos de YouTube se rigen también por la Política de Privacidad de Google.

Datos a los que accede

Con la autorización OAuth del propietario, solo pide dos permisos sobre su propio canal: youtube.upload (subir vídeos) y youtube.force-ssl (miniaturas, listas de reproducción, comentarios propios en sus propios vídeos y leer el nombre del canal autorizado). No accede a datos de otros usuarios ni muestra contenido de YouTube a nadie.

Datos que guarda

Solo en el ordenador del propietario: los tokens OAuth de sus dos canales y un registro de subidas (ID, título y fecha de cada vídeo subido). No hay servidores, no se venden ni se comparten datos con terceros, y no hay cookies, analítica ni publicidad.

Conservación y eliminación

Los datos se guardan solo mientras se usa la herramienta y se pueden borrar en cualquier momento eliminando la carpeta de tokens y el registro local. El acceso se puede revocar en https://security.google.com/settings/security/permissions; al revocarlo, los tokens dejan de funcionar y pueden borrarse.
